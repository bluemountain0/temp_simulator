# TECH_DEBT — 기술부채 목록

> 임시 구현·미해결 문제·"언젠가 고쳐야 할 것" 모음.
> OMC project_memory와 다른 점 — 이 파일은 git 추적, 영구 기록, 사람도 읽음.

## 형식

```
### [번호] 제목
- **위치**: 파일/심볼
- **현황**: 지금 무엇이 부족한가
- **임시 해결**: 현재 어떻게 우회하는가
- **올바른 해결**: 본 수정 방향
- **블로커**: 무엇이 있어야 해결 가능한가
- **우선순위**: 높/중/낮
```

---

### 1. Phase 2 FEM 솔버 미구현

- **위치**: `fem_model.py` — `FEMSolver.solve()` 가 `NotImplementedError`
- **현황**: 1D 가정으로 t > 100 ms DC에서 W 표면 온도 과대 추정 (±30~50%)
- **임시 해결**: HybridFDSolver의 클램프(`MAX_T_EXPOSURE_SURFACE`)로 발산 방지
- **올바른 해결**: r-z 축대칭 2D FDM (횡방향 열확산 반영)
- **블로커**: 사용자 결정, 메싱 라이브러리 선택
- **우선순위**: 중

### 2. 실험 검증 데이터 부재

- **위치**: `tests/test_validation.py` 전체
- **현황**: 모델 예측을 검증할 실제 측정 온도 데이터 없음
- **임시 해결**: 물리적 일관성(단조성·보존)만 oracle 테스트로 검증
- **올바른 해결**: Phase 3 — 열전대/IR 카메라 실측 후 보정
- **블로커**: 실험 PC + 측정 장비, 실험 일정
- **우선순위**: 높

### 3. 핀 두께 도면 미기재

- **위치**: `geometry.TubeGeometry.fin_thickness = 0.8e-3`
- **현황**: 핀 간격 패턴으로부터 추정한 0.8 mm
- **임시 해결**: GUI에서 `GeometryOverride.fin_thickness`로 수동 조정 가능
- **올바른 해결**: 도면 또는 실측으로 정확값 확인 후 기본값 갱신
- **블로커**: 도면 보강
- **우선순위**: 중

### 4. Streamlit 캐시 무효화 불안정

- **위치**: `app.py` `run_sim()` `@st.cache_data`
- **현황**: dataclass 필드 추가 시 캐시 키 재계산 보장 안 됨 (일부 케이스)
- **임시 해결**: 사용자가 브라우저 새로고침
- **올바른 해결**: `hash_funcs=` 명시 또는 `ttl` 도입
- **블로커**: 없음 (작업 가능)
- **우선순위**: 낮

### 5. CI/CD 부재

- **위치**: 저장소 루트
- **현황**: push마다 자동 테스트 없음
- **임시 해결**: 개발자가 수동으로 `pytest tests/ -v`
- **올바른 해결**: `.github/workflows/test.yml`
- **블로커**: GitHub repo 공개/접근 권한 확인 필요
- **우선순위**: 중

### 6. 의존성 버전 잠금 없음

- **위치**: `requirements.txt` (하한만 표기 `>=`)
- **현황**: 새 환경 설치 시 라이브러리 버전이 달라질 수 있음
- **임시 해결**: 개발 PC와 실험 PC가 같은 시점에 설치된 환경 가정
- **올바른 해결**: `pip freeze > requirements.lock` 또는 poetry 도입
- **블로커**: 없음
- **우선순위**: 중

### 7. `app.py` 단일 파일 과대

- **위치**: `app.py` (~300줄)
- **현황**: 입력 폼/계산 호출/그래프 렌더링이 모두 한 파일
- **임시 해결**: 모듈 상수(`LEVEL_COLORS`, `THRESHOLD_LINES`)로 부분 분리
- **올바른 해결**: `ui_inputs.py`, `ui_render.py`로 분리
- **블로커**: 없음 (단, Streamlit 페이지 라우팅 패턴 결정 필요)
- **우선순위**: 낮

### 8. 손상 임계값 출처 미문서화

- **위치**: `damage.py _THRESHOLDS`
- **현황**: 700°C 안전 마진 17% 등 일부 출처가 코드 주석에만 존재
- **임시 해결**: AGENTS.md 임계값 표 참조
- **올바른 해결**: `docs/DECISIONS.md`에 임계값별 1차 출처/논문/표준 기록
- **블로커**: 없음
- **우선순위**: 낮
